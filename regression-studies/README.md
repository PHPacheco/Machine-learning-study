# Regression Studies

This directory contains the three stages of the regression assignment:

- `simple_linear_regression.ipynb`: correlation and straight-line fitting
- `multiple_linear_regression.ipynb`: house price estimation from size and number of bedrooms
- `polynomial_regression.ipynb`: comparison of polynomial degrees and overfitting

The notebooks load their datasets from `data/`. To open the multiple regression
study from the repository root, run:

```bash
python -m jupyter lab regression-studies/multiple_linear_regression.ipynb
```
